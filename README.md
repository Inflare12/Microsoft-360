# Microsoft-360

A free, independent productivity suite inspired by the workflows of modern office software. This project does not contain Microsoft proprietary source code.

## Apps
- Writer — rich document editor
- Sheets — spreadsheet workspace
- Slides — presentation editor

## Principles
- Free to use
- Offline-first
- Open formats where practical
- No Microsoft proprietary code

Microsoft Open XML specifications are publicly documented and can be implemented independently. See the official Microsoft Open Specifications documentation for compatibility work.
